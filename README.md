# 🛒 Virtual Store

A responsive **e-commerce web application** built with **HTML, CSS, JavaScript, Bootstrap, and Local Storage**. The project demonstrates common front-end development concepts such as dynamic rendering, filtering, pagination, state management, and a shopping cart without requiring a backend.

## ✨ Features

- 📦 Product catalog
- 🔍 Search products by name
- 🏷️ Filter by category
- 💲 Filter by maximum price
- ↕️ Sort products
  - Name (A-Z)
  - Name (Z-A)
  - Price (Low to High)
  - Price (High to Low)
- 📄 Pagination
- 📋 Product details page
- 🛒 Shopping cart
- ➕ Increase/decrease product quantity
- ❌ Remove items from cart
- 🗑️ Clear shopping cart
- 💾 Cart persistence using Local Storage
- 🔔 Bootstrap toast notifications
- 💳 Checkout page
- 📱 Fully responsive layout with Bootstrap

## 💾 Local Storage

The project uses the browser's Local Storage to persist:

- Shopping cart contents
- Product quantities

The cart remains available after refreshing or reopening the browser.
